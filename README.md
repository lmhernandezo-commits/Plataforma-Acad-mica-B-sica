# Plataforma Académica Básica

Esta aplicación muy sencilla presenta información básica sobre la creación de las computadoras.

## Contenido

- `index.html`: página web con historia breve sobre el origen de las computadoras.
- `style.css`: estilos simples para una presentación limpia.
- `script.js`: archivo JavaScript listo para futuras mejoras.

## Objetivo

Aprender de forma sencilla cómo nacieron las primeras máquinas calculadoras y cómo evolucionaron hasta las primeras computadoras electrónicas.
